<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install flowinger
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add flowinger
    ```

  </TabItem>
  <TabItem label="yarn">

  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add flowinger
    ```
  </TabItem>

React 18 or 19 is the only peer dependency. There is no stylesheet to import. The package ships ESM, CommonJS
and TypeScript declarations.

## Why Flowinger

<Bento>
  <Tile title="Small, and only what you use" icon="rocket" size="large" href="docs/features/" cta="Features">
    The core is about 20.9 kB gzipped. Drag, connect, selection and the rest are opt-in features that add only
    their own code, so the whole canvas is about 39 kB.
    <SizeBars slot="visual" />
  </Tile>
  <Tile title="No dependencies" icon="puzzle" href="docs/theming/" cta="Theming">
    `react` and `react-dom` are the only peers. Plain DOM, SVG and CSS variables; no stylesheet to import.
  </Tile>
  <Tile title="An API you already know" icon="approve-check" href="docs/react-flow-coverage/" cta="Coverage">
    React Flow’s names for components, hooks, props, class names and types — all 220 of React Flow 13's exports,
    measured from its own type declarations.
  </Tile>
  <Tile title="Fast at 10,000 nodes" icon="analytics" size="large" href="docs/benchmarks/" cta="Benchmarks">
    Without culling, it mounts, pans and zooms for less than React Flow 13; with culling, it mounts about ten
    times as fast. React Flow 13 drags faster without culling.
    <MountRace slot="visual" />
  </Tile>
  <Tile title="The “pro” extras, free" icon="star" size="half" href="docs/pro/" cta="Pro modules">
    Undo/redo, copy and paste, snap guides, export, smart edges, flowchart shapes and a collapsible tree, each
    its own entry point.
  </Tile>
  <Tile title="Server rendering that works" icon="laptop" size="half" href="docs/server-rendering/" cta="Server rendering">
    Renders and hydrates on React 18 and 19, with the first paint already framed.
  </Tile>
</Bento>

## Flowinger and React Flow

<div class="flowinger-compare">

| | Flowinger 2 | React Flow 13 |
|---|---|---|
| Runtime dependencies | **0** | 4 direct, plus `d3-zoom`, `d3-drag`, `d3-selection`… |
| Stylesheet to import | **None** (CSS variables) | `@xyflow/react/dist/style.css` |
| Diagram chunk in a real app ([QueryLens](https://query-lens.1234naveenboddepalli.workers.dev), flowinger 1.1 against React Flow 12) | **20.2 kB** gzipped | 59.1 kB gzipped |
| Mount 10,000 nodes | **0.8 s** | 1.45 s |
| Mount 10,000 nodes, culled | **55 ms** | 541 ms |
| Drag at 10,000 nodes, no culling | 86 ms a move | **57 ms** a move |
| Undo/redo, copy-paste, snap lines, export, smart edges | **Free**, separate entry points | [React Flow Pro](https://reactflow.dev/pro) (paid) |
| Ecosystem, examples, answers online | Small and new | **Large and mature** |

</div>

The full table, with panning and zooming culled and not, is in the
[benchmarks](docs/benchmarks/).
