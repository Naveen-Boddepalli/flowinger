## Install

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install flowinger
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add flowinger
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add flowinger
    ```
  </TabItem>
  <TabItem label="bun">
    ```bash
    bun add flowinger
    ```
  </TabItem>
</Tabs>

React 18 or 19 is the only peer dependency. There is no stylesheet to import. The package ships ESM, CommonJS
and TypeScript declarations.

## Why Flowinger

<CardGrid>
  <Card title="Small, and only what you use" icon="rocket">
    The core is about 19.6 kB gzipped. Drag, connect, selection and the rest are opt-in features that add only
    their own code, so the whole canvas is about 35.4 kB. [Features →](docs/features/)
  </Card>
  <Card title="No dependencies" icon="puzzle">
    `react` and `react-dom` are the only peers. Plain DOM, SVG and CSS variables; no stylesheet to import.
    [Theming →](docs/theming/)
  </Card>
  <Card title="An API you already know" icon="approve-check">
    React Flow’s names for components, hooks, props, class names and types — all 211 of its exports, measured
    from its own type declarations. [Coverage →](docs/react-flow-coverage/)
  </Card>
  <Card title="The “pro” extras, free" icon="star">
    Undo/redo, copy and paste, snap guides, export, smart edges, flowchart shapes and a collapsible tree, each
    its own entry point. [Pro modules →](docs/pro/)
  </Card>
  <Card title="Server rendering that works" icon="laptop">
    Renders and hydrates on React 18 and 19, with the first paint already framed.
    [Server rendering →](docs/server-rendering/)
  </Card>
  <Card title="Fast at 10,000 nodes" icon="analytics">
    Mounts 10,000 nodes in 0.6 s against React Flow’s 1.3 s, and pans them in a quarter of the time without
    culling. [Benchmarks →](docs/benchmarks/)
  </Card>
</CardGrid>

## Flowinger and React Flow

<div class="flowinger-compare">

| | Flowinger | React Flow (`@xyflow/react` 12) |
|---|---|---|
| Runtime dependencies | **0** | 3 direct, plus `d3-zoom`, `d3-drag`, `d3-selection`… |
| Stylesheet to import | **None** (CSS variables) | `@xyflow/react/dist/style.css` |
| Diagram chunk in a real app ([QueryLens](https://github.com/Naveen-Boddepalli/QueryLens)) | **19.0 kB** gzipped | 60.5 kB gzipped |
| Mount 10,000 nodes | **0.6 s** | 1.3 s |
| Undo/redo, copy-paste, snap lines, export, smart edges | **Free**, separate entry points | [React Flow Pro](https://reactflow.dev/pro) (paid) |
| Ecosystem, examples, answers online | Small and new | **Large and mature** |

</div>

The full table, with panning and zooming culled and not, is in the
[benchmarks](docs/benchmarks/).
